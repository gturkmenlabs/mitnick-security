# mitnick-security

Kevin D. Mitnick ve William L. Simon'ın *Aldatma Sanatı* (The Art of Deception), *Sızma Sanatı* (The Art of Intrusion) ve *Ghost in the Wires* kitaplarından derlenmiş, savunma odaklı bir Claude Code skill'i: toplum mühendisliği, kimlik doğrulama, sızma vakaları ve güvenlik süreçleri.

## Kurulum

```sh
git clone https://github.com/gturkmenlabs/mitnick-security ~/.claude/skills/mitnick-security
```

Claude Code içinde `/mitnick-security <soru>` ile çağrılır.

## İçerik

- `SKILL.md` — giriş noktası, temel kararlar ve dizin
- `chapters/` — bölüm bazında özetler, vakalar ve karşı önlemler
- `cheatsheet.md`, `patterns.md`, `glossary.md` — karar özeti, yöntemler, sözlük

## Not

Bu depo kitapların metnini içermez; bölümlerin özetini, yorumunu ve savunma odaklı çıkarımlarını içerir. Kitapların telif hakları yazarlarına ve yayıncılarına aittir. İçerik eğitim ve savunma amaçlıdır; güncel teknik veya hukuki rehber yerine geçmez.
